Fairness ledger

Which promises each method keeps

Mathematicians test single-winner methods against fairness criteria. No method passes them all; Arrow and Gibbard proved none can. Each method chooses which flaw to live with.

Method Elects the Condorcet winner when there is one A first-choice majority always wins More support never hurts (monotonic) Ranking a backup can’t hurt your favorite Similar candidates don’t split the vote Ballot

Condorcet row assumes a modern Condorcet method such as Ranked Pairs or Schulze. Approval, score and majority judgment pass the split-vote test as long as voters grade each candidate on its own merits. Criteria definitions follow the standard social-choice literature.
