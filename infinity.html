Infinity · endless, and then some

Some infinities are bigger than others.

Infinity isn’t a very big number. It’s a different kind of thing, and it breaks the rules that work for ordinary quantities: a full hotel can always take more guests, half of something can be as big as the whole, and you can add up forever and still get a finite answer. Mathematicians took 2,000 years to tame it. Here’s how.

Demo 1 · a strange hotel

Hilbert’s Grand Hotel

David Hilbert imagined a hotel with infinitely many rooms, every one of them occupied. A new guest arrives. No problem. Then a coach with infinitely many passengers. Still no problem. Try it.

The rule that changedFor finite things, “full” means no room for more. For infinite sets, a part can be matched one-to-one with the whole. That is the definition of infinite that Richard Dedekind gave in 1888.
Demo 2 · counting

You can count every fraction

There are infinitely many fractions between 0 and 1 alone, so surely there are more fractions than counting numbers? No. Georg Cantor showed you can list them all by zigzagging through a grid, skipping repeats like 2/2. Every fraction gets a number, so the two infinities are the same size.

The list so far
CountableAny infinite set you can put into a list like this, first, second, third…, is called countable. Its size is written ℵ₀ (“aleph-null”), the smallest infinity.
Demo 3 · a bigger infinity

Cantor’s diagonal argument

Now try to list every infinite string of 0s and 1s (each is like a real number written in binary). Cantor’s trick, from 1891: walk down the diagonal and flip every digit. The new string differs from row 1 in digit 1, from row 2 in digit 2, and so on. It can’t be anywhere in the list, however you made the list.

The new string

UncountableThe real numbers can’t be listed, so their infinity is strictly bigger than the counting numbers. And Cantor proved there is no biggest infinity at all: for any set, the set of all its subsets is always bigger.

Endless sums, finite answers (sometimes)

Zeno of Elea argued, around 450 BCE, that you can never cross a room: first you must cover half, then half of what’s left, and so on forever. The answer took two thousand years: infinitely many steps can add up to a finite total. But not always. Pick a sum.

Zoom forever: the Mandelbrot set

Take a number, square it, add a constant c, and repeat. If the result stays small forever, c is in the Mandelbrot set (black). The rule fits on one line, yet the edge has infinite detail: zoom in anywhere and new spirals, seahorses and tiny copies of the whole set keep appearing. Tap to zoom in.
